# 22:22 — дизайн-система «Рожевий маркер»

Світлий застосунок для знайомства жінок. Настрій — тепло, по-дівочому, як записка від подруги або сторінка щоденника. Чистий спокійний інтерфейс і кілька «ручних» штрихів поверх нього: рожевий маркер, полароїд зі скотчем, примітка на полях.

## Що в папці

| Файл | Що це |
|---|---|
| `tokens.css` | Усі кольори, шрифти, розміри, радіуси як CSS-змінні. Джерело правди. |
| `assets/*.svg` | Ручні штрихи: маркер, підкреслення, стрілки, сердечко, обведення. |
| `screens/01–04-*.html` | Еталонні екрани (390×844): знайомство, анкета, збіг, профіль. |
| `screens/00-*.html` | Аркуші системи: кольори і шрифти, фірмові штрихи, компоненти. |

Відкрий будь-який `.html` у браузері, щоб побачити, як має виглядати результат.

## Шрифти

- **Ysabeau Infant** (400–800) — увесь інтерфейс. Заголовки 800, відповіді 600, текст 500.
- **Bad Script** — тільки примітки на полях і підписи під фото. До двох рядків. Ніколи — кнопки, поля, важливий текст.

Обидва з Google Fonts, обидва з кирилицею.

## Фірмові штрихи — правила

1. **Рожевий маркер** (`assets/marker.svg`) — під одним словом на екран: ім’я, ключове слово заголовка або вибрана відповідь. SVG позиційований абсолютно під текстом: `left: -8px; bottom: 2–6px; width: 108–116%; height: 52–60%`, `preserveAspectRatio="none"`. Текст поверх (`position: relative`).
2. **Полароїд і скотч** — усі фото людей. Біла рамка (padding 8–11 px, знизу 26–46 px під підпис), `--shadow-paper`, нахил від −6° до +5°. Підпис від руки (Bad Script). Скотч — прямокутник `--tape` приблизно 60–84×20–26 px, нахил 5–40°, зверху або на кут.
3. **Примітка на полях** — одна на екран, колір `--raspberry`, Bad Script 19–20 px, нахил 2–4°, зі стрілкою (`arrow-*.svg`), що веде до предмета розмови. Говорить як подруга: «у вас обох — книжки», «це завжди можна змінити потім», «написати першою — це нормально».
4. **Дрібниці від руки** — `underline.svg` під текстовими посиланнями («Пізніше», «На головну»), `circle.svg` навколо цифр і часу, `heart.svg` — тільки на екрані збігу.

Усе інше — спокійне й рівне: без нахилів, без тіней, без анімацій.

## Компоненти

- **Головна кнопка**: `--ink` фон, `--paper` текст, висота 58, пігулка, 18/700. Одна на екран.
- **Друга кнопка**: прозора, межа 1.5 px `--line`.
- **Текстове посилання**: 17–18/700 + `underline.svg` під ним.
- **Іконкова кнопка**: 44–48 px, біле коло, межа 1.5 px `--line`, лінійна іконка 1.8 px.
- **Поле**: висота 56–58, радіус 18, межа 1.5 px. У спокої — фон `--paper` або білий, у фокусі — білий + межа `--ink`, помилка — межа і текст `--error`. Підпис над полем 16/600 `--coffee`.
- **Варіант відповіді**: висота 62, радіус 18, біла картка, межа `--line`, справа порожнє коло. Вибраний — межа `--ink`, текст 800 з маркером під ним, справа чорнильне коло з галочкою.
- **Чип**: висота 44, пігулка. Вибраний — `--petal` + межа `--marker`.
- **Перемикач**: 54×32, увімкнений — трек `--ink`, повзунок `--marker`.
- **Прогрес анкети**: «Питання 2 з 7» 15/600 `--grey` + смужка 6 px, трек `#EFE9E2`, заповнення `--ink`.
- **Картка відповіді**: радіус 20, біла, межа `--line`, питання 15/600 `--grey`, відповідь 17–19/600 `--ink`.
- **Тост**: чорнильна пігулка, текст `--paper`, галочка `--marker`.

## Як передати в Claude Code

1. Поклади цю папку в репозиторій застосунку, наприклад у `design/2222-design-system/`.
2. Напиши в Claude Code щось на кшталт:

> Прочитай `design/2222-design-system/README.md` і `tokens.css` — це наша дизайн-система. Еталонні екрани лежать у `screens/`, ручні штрихи — в `assets/`. Перенеси токени в наш проєкт (тема, кольори, шрифти), зроби компоненти за розділом «Компоненти», а потім переверстай екран профілю так, як у `screens/04-profil.html`. Дотримуйся правил фірмових штрихів: одне виділення маркером і одна примітка на екран.

3. Далі проси екран за екраном, посилаючись на відповідний файл у `screens/`.

Якщо застосунок не на вебі (наприклад, React Native чи SwiftUI), токени з `tokens.css` переносяться в тему як є, а SVG-файли — як векторні ресурси.
